Build a complete, modern, production-style AI-powered web application called **SkillGap AI**.

### 1. PRODUCT IDEA

SkillGap AI helps college students understand what skills they are missing for their desired career.

The user provides:

* Degree / branch
* Current technical and soft skills
* Target job / career
* Projects completed
* Experience level
* Interests

The application analyzes the student's current profile against the requirements of the selected career and generates:

1. Skill-gap analysis
2. Skill priority levels
3. Personalized learning roadmap
4. Recommended projects
5. Weekly learning plan
6. Progress tracker
7. Career readiness percentage
8. Recommended resources

The core concept is:

**Current Skills → Target Career → Skill Gap → Priority → Learning Roadmap → Projects → Progress**

Do NOT make this look like a generic AI chatbot. The website should feel like a real AI career-planning SaaS product designed specifically for college students.
